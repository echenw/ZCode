# 代理通信显示转换

Root Registry 仍独占代理身份和邮箱状态。本模块只把持久化会话、工具结果及 drain 事件转换为可展示数据。

- `index.ts` 是浏览器可用的纯转换入口，不导入 Node 或数据库适配器；冷恢复、回放和实时投影共用 provenance 规则。
- `materialize.ts` 是宿主的读取入口，只通过注入的 store 读取当前会话与同项目祖先图；不冷启动或写入会话。
- 只按同一个 messageId 的持久化 inputPresentation 补全来信来源。用户粘贴同样的 envelope 仍是用户输入。
- 名称只是展示别名。收件人寻址、ACK、原始正文、运行代次和取消范围保持原契约。
- 完成事件和普通来信都保留原始内容；展示去除宿主 carrier，模型收到的原文不变。

- 正式 operation 来自执行器元数据或经 Store 交叉校验的 Root 图，只参与工具展示与生命周期补全；不从任意 wire 后缀推断 MCP 身份。
- 原生 spawn 的工具完成是接纳 ACK，不能直接合成代理成功。恢复事件保持独立 ID；图中未完成执行投影为 lost，当前进程的正式生命周期事件优先。
